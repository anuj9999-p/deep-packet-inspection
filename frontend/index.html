The engine

One binary. Three protocol layers. Zero shortcuts.

The web layer you're looking at is just glue. All inspection work — reading the raw PCAP frames, walking the Ethernet/IP/TCP/UDP headers, and classifying traffic — happens inside a compiled C++ binary. FastAPI hands it a file and reports back exactly what the engine found.

01

Frame-accurate parsing

Reads the PCAP global header and every packet record directly from bytes — handling both native and byte-swapped captures — then decodes Ethernet, IPv4, TCP, and UDP headers field by field.

02

Flow & protocol classification

Every packet is tagged by transport protocol and, where applicable, by well-known application ports — HTTP, HTTPS, and DNS — with source and destination endpoints tracked across the whole capture.

03

Reproducible artifacts

Each run emits a machine-readable report.json and a passthrough output.pcap, so results can be automated, diffed, or re-opened in Wireshark.
